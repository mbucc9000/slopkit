MessageSearch

Search your messages like newer iOS.

Install

Open in Cydia Add slopkit to Cydia

How to Use

  1. In Messages, pull down on the conversation list to show the search bar, then type.
  2. Matching conversations show first, then every matching message. Tap one to jump to it.
  3. The first time, older messages are indexed in the background. The list shows how far along it is.

There are no settings to configure.

What it does

  • Pull down in Messages and type: every matching message shows, newest first, not just one per conversation.
  • Your search words are in bold, and conversations whose name or number matches show up top.
  • Tap a message to jump straight to it, even an older one. The bubble flashes so you can spot it.
  • Fast because it keeps its own index on the phone. The first build runs in the background, then only new messages are added.
