What it does

Sets up an iOS 6 iPhone for a US Mobile Dark Star SIM (AT&T network) automatically: install it and cellular data and MMS are set up, with nothing to type in. Uninstalling puts back what was there before.

  • Sets up cellular data and MMS for a US Mobile Dark Star SIM automatically when you install it.
  • Fills in the same settings you'd otherwise type into Settings › General › Cellular › Cellular Data Network.
  • Uninstalling puts back what was there before.
