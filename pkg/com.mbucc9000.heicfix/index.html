How to Use

  1. Install HEICFix, then open Messages.
  2. HEIC photos you already have turn into normal photos a few seconds later, and new ones convert as they arrive.
  3. There's nothing to set up.

There are no settings to configure.

What it does

  • Newer iPhones send camera photos as HEIC, which iOS 6 can't open, so they arrive as broken file bubbles. With HEICFix they show like any other photo.
  • Each one is turned into a JPEG on this iPhone, in about a second, as soon as it downloads. No server.
  • Works in the chat, full screen, and when you save the photo.
  • Photos you got before installing are converted the next time you open Messages.
  • The original file is never changed. Removing HEICFix deletes the JPEG copies.
